## About

Obscure is a customizable new tab page that aims to be more than just a search box.

Alongside quick access to multiple search engines, the long-term goal is to support search engines created by the community. Anyone should be able to build their own search experience and make it discoverable through Obscure.

---

## Features

- Custom new tab page
- Multiple search engine support
- NASA Astronomy Picture of the Day
- Fast search interface
- Community search engine support *(planned)*
- Browser extension

---

## How it Works

```text
Open New Tab
      ↓
Choose Search Engine
      ↓
Enter Query
      ↓
Search
```

## Technologies

- JavaScript
- HTML
- CSS
- NASA APOD API
- GitHub Actions

## Running Locally

Clone the repository:

```bash
git clone https://github.com/aamosm/Obscure.git
cd Obscure
```

Load the extension into your browser using Developer Mode.
